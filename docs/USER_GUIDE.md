# CMX Material Manager 사용 가이드

## 01 / 기준 파일 - 편집할 라이브러리 열기

**CMX 열기** 또는 `Ctrl+O` 사용. 선택한 파일의 물질 목록 표시. 검색란에서 이름·물성 종류 검색. 기준 파일은 일괄 저장 대상에 항상 포함.

새 파일을 만들 목적이라면 기존 라이브러리를 열고 편집 후 **CMX 내보내기** 사용. 기준 파일은 그대로 유지.

## 02 / 물질 편집 - 정보와 모델 구분

| 화면 | 입력 내용 |
| --- | --- |
| 물질 정보 | 이름, 기본 두께, 상한·하한 공차 |
| 속성 / 모델 | 모델 선택, 모델 속성, 행별 물성 값 |
| XML 편집 | 선택 물질의 전체 XML, 특수·확장 구조 |

두께·공차 예: `35um`, `1.4MIL`. 표의 머리글과 원본 데이터 정의에서 단위 확인. 주파수·온도별 행과 모델을 구분할 것. `Model` 복제 후 `Temperature` 등의 조건 변경 가능.

**편집 반영**은 메모리의 저장 대기 목록에만 반영. 디스크 저장은 일괄 저장 또는 내보내기에서 수행. 파란색 선택 항목과 편집 중인 물질 이름 확인.

**새 물질**: 이름과 시작 모델 선택. **복제**: 기존 물질을 새 이름으로 추가. 생성된 초기값은 예제이므로 실제 물성으로 수정할 것.

**선택 변경 취소**: 해당 물질의 편집·저장 대기·동기화 포함 취소. 기존 물질은 처음 연 값으로 복원, 새 물질은 목록에서 제거. 다른 물질의 변경은 유지.

## 03 / 경로 목록 - 여러 라이브러리 지정

**파일 추가**로 CMX 여러 개 선택. **경로 붙여넣기** 또는 **목록 열기**로 줄 단위 경로 지정. 텍스트 파일 인코딩은 UTF-8.

```text
C:\MaterialLibraries\Allegro\material.cmx
D:\MaterialLibraries\Sigrity\material.cmx
```

체크한 대상과 기준 파일에 일괄 저장. **목록 저장**으로 경로 목록 내보내기. 앱 재시작 시 기억한 대상은 체크 해제 상태이며, 다시 열린 기준 파일은 자동 포함.

물질 일부를 배포하려면 목록에서 `Ctrl+클릭`으로 개별 항목 추가·해제, `Shift+클릭`으로 범위 선택. **선택 물질 동기화에 포함**을 눌러 화면에서 선택한 물질을 저장 대기에 추가. 검색어를 바꿔 다른 물질을 추가한 후 한 번에 저장 가능. 편집기는 현재 물질 한 개를 표시.

라이브러리 전체를 배포하려면 **전체 자동 동기화** 선택. 검색·선택 범위와 관계없이 편집·신규 물질을 포함한 기준 라이브러리 전체와 체크된 대상을 자동 비교. 대상에 없는 물질은 추가, 다른 동명 물질은 갱신, 대상에만 있는 물질은 유지. 미리보기에서 **백업 후 저장**을 누르면 차이가 있는 파일만 저장.

## 04 / 일괄 저장 - 미리보기와 백업 확인

1. **변경 미리보기 / 일괄 저장** 또는 `Ctrl+S` 선택.
2. 파일별 추가·수정·이름 변경과 XML 차이 확인.
3. **백업 후 저장** 선택.
4. 완료 창의 세부 정보에서 파일별 백업 경로 확인.

**같은 이름의 물질 전체가 기준 내용으로 교체됨. 대상 물질의 별도 속성도 교체 대상.** 다른 이름의 물질과 문서 메타데이터는 유지. 새 물질도 대상에 같은 이름이 있으면 갱신. 이름 변경이 다른 기존 물질과 충돌하면 중단.

대상 중 하나라도 XML·버전·열·단위가 맞지 않으면 저장 시작 전 중단. 미리보기 후 외부에서 수정한 파일도 저장 중단. 저장 오류 시 이미 교체한 파일은 복원 시도; 복원 실패 경로는 오류 창에서 확인.

백업 이름: `material.cmx.<고유값>.bak`. 백업은 원본과 같은 폴더에 유지. 복원 시 Cadence 애플리케이션을 닫고 백업을 원래 경로·이름으로 복사할 것.

## 05 / CMX 내보내기 - 별도 전체 라이브러리 저장

**CMX 내보내기** 선택 후 저장 위치 지정. 현재 기준 라이브러리 전체와 편집·신규 물질을 합친 CMX 생성. 기준 파일과 경로 목록의 파일은 변경하지 않음.

출력 파일이 이미 있으면 덮어쓰기 확인 후 백업 생성. 기준 파일과 같은 경로로 내보내기는 불가. 기준 파일을 수정하려면 일괄 저장 사용. 내보내기 후에도 일괄 저장 대기 상태는 유지.

## 06 / 운용 조건 - 애플리케이션과 권한

- Cadence에서 대상 파일을 열고 있다면 종료 후 저장할 것. 저장 후 해당 제품에서 라이브러리를 다시 불러올 것.
- 보호된 폴더는 쓰기 권한 필요. 일반 실행으로 저장이 거부되면 쓰기 가능한 폴더로 내보내거나, 필요할 때 앱을 관리자 권한으로 실행할 것.
- 여러 파일 저장 중 전원 차단 시 자동 복원 보장 불가. 각 폴더의 백업으로 복원할 것.
- 동일 CMX 스키마끼리 동기화. 제품 버전별 스키마 변환·원격 파일 잠금·Cadence 캐시 강제 갱신 미지원.
- XML 외부 엔터티·DOCTYPE 거부. 원본 바이트 보존이 불가능한 일부 레거시 인코딩 파일은 변경 거부.

## 07 / 화면과 단축키

왼쪽 물질 목록, 오른쪽 편집기, 아래 대상 경로 구성. 구분선을 끌어 영역 크기 조절. 작은 창에서는 편집 영역의 스크롤 사용.

| 단축키 | 기능 |
| --- | --- |
| Ctrl+O | 기준 파일 열기 |
| Ctrl+F | 검색란 이동 |
| Ctrl+A (물질 목록) | 현재 검색 결과 전체 선택 |
| Ctrl+S | 변경 미리보기 / 일괄 저장 |
